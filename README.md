# The Heritage Short: a storyboard-to-film pipeline

A 60–90 second family-heritage short film, narrated in Amharic with English subtitles and an original score, generated by a five-stage pipeline from one contract file: `storyboard.json`.

## Run it

```bash
git clone <this repo> && cd heritage-short
cp .env.example .env        # add GEMINI_API_KEY, CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_API_TOKEN
make film                   # = python pipeline/run_all.py
```

Requirements: Python 3.10+, FFmpeg with libass (for subtitles). Optional: `pip install jsonschema` (there is a built-in fallback validator).
No keys yet? `make dry-run` runs the whole pipeline with placeholder audio and images, so you can check it works.

Output: `outputs/final/heritage_short_16x9.mp4` and `outputs/final/heritage_short_9x16.mp4`.

## Stages

| Stage | Script | Model | Runs on |
|---|---|---|---|
| validate | `common.load_storyboard` | JSON Schema | local |
| narration | `pipeline/narration.py` | Gemini Flash TTS | Gemini API (free) |
| keyframes | `pipeline/keyframes.py` | FLUX.1 schnell | Cloudflare Workers AI (free) |
| moving shots | `kaggle/wan_shots.py` → `pipeline/shots.py` | Wan 2.2 TI2V-5B, Ken Burns fallback | Kaggle T4 / local FFmpeg |
| music | `kaggle/acestep_score.md` → `pipeline/music.py` | ACE-Step 1.5 | Kaggle |
| assembly | `pipeline/assemble.py` | FFmpeg | local |

Change one shot's `narration` or `image_prompt` in `storyboard.json` and re-run `make film`: only that shot is regenerated (see `outputs/.cache/` and the new line in `runs.jsonl`).
